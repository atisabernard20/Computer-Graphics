# Troll Platformer (Level Devil-Style)
2D rage platformer with 2-player split-screen race and custom camera/culling math.

## Work Packages & Branches
- `feature/player-physics`: Movement, variable jump, coyote time
- `feature/traps-levels`: 8 trap types, JSON/text level formats
- `feature/camera-viewports`: Split-screen viewports, minimap, culling
- `feature/level-editor`: In-game tile/trap editor with save/load
- `feature/art-audio`: Sprites and sound effects
